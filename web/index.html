Interventions apply to the steered run. dose follows the recipe: adds dose × median‖resid‖ / ‖W_down[:,n]‖ to the neuron at every position — about ±0.5–1 changes behaviour, past ~1.5 output tends to collapse. add adds a raw value, clamp pins it (0 = ablate).

Dose sweep

Runs the prompt from Chat once per factor in a single batch: every dose is multiplied by the factor (×0 = baseline, negative = pushed the other way).

Find neurons behind a behaviour, steer them, then A/B test against random neurons of the same layers at the same dose: a real find beats nearly all of them. The full pipeline (exact checks, screening on unseen prompts, dose curves) is scripts/hunt.py.
